## Design discussion before M2 ✅

| ID   | Question                                         | Note                                                                                                            |
| ---- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| D2.1 | 哪些接口直接发 HTTP，哪些必须走浏览器？          | ✅ 只有网页搜索的排序要浏览器，其余都直接 HTTP，见 `CLAUDE.md`                                                  |
| D2.2 | 字体还原用静态字符表，还是读页面字体动态生成？   | ✅ 按字形轮廓查汉字，字体按响应现场取，见 `CLAUDE.md`                                                           |

**Exit criteria:** 用户批准这些决策。决策写进项目的 `CLAUDE.md`。⬜ 决策已写进 `CLAUDE.md`，等你批准。
